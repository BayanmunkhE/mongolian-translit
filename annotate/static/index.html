Ctrl + Enter = хадгалаад дараах
Хийх мөр үлдсэнгүй. Доороос «CSV татах»-г дараад python tools/real_test.py import real_test_todo.csv командаар тест рүү нэмнэ үү. Өмнөх мөрүүдийг засах бол
Заавар
  • Латин талыг өөрчлөхгүй. Алдаатай ч бичсэнээр нь үлдээнэ.
  • Кирилл талд бичсэн хүний хэлэх гэсэн зүйлийг зөв бичгээр бичнэ: ө/ү, х, й/ь, урт эгшиг (margash → маргааш), үсгийн алдааг засна.
  • Товчлолыг бүтэн бичнэ (bn → байна, bh → байх). Эргэлзвэл тэмдэглэлд бичнэ.
  • Англи үг, тоо, emoji-г өөрчлөхгүй (2023, like, <3).
  • Том, жижиг үсгийг эх мессежийнх шиг үлдээнэ.
  • Монгол биш, утгагүй, эсвэл хэн нэгний хувийн мэдээлэлтэй бол «Алгасах».
  • «Дүрмийн таамаг» нь зөвхөн туслах. Нейрон загварын гаралтыг хэзээ ч ашиглахгүй.
